# FakeStore API

A responsive React application that fetches and displays products using the FakeStore API. Users can browse products, view details, and enjoy a clean responsive interface.

## 🚀 Features

- Fetch products from FakeStore API
- Product listing
- Product details
- Responsive UI
- Loading and error handling
- Clean React components

## 🛠️ Tech Stack

- React.js
- JavaScript (ES6)
- Vite
- Tailwind CSS
- FakeStore API
